Крестики-нолики (Tic-Tac-Toe)
Классическая игра «Крестики-нолики» на поле 3×3 с графическим интерфейсом, реализованная на C# с использованием Windows Forms.

Цель проекта
Создать простое и удобное приложение для игры в крестики-нолики, которое можно использовать для игры вдвоём за одним компьютером
или против компьютера (если этот режим реализован). Проект написан в учебных целях для демонстрации навыков разработки на C# и работы с событиями в Windows Forms.

Технологии
Язык: C#
Платформа: .NET Framework 
Интерфейс: Windows Forms

Как запустить?
1. Убедитесь, что у вас установлена подходящая версия .NET (обычно .NET Framework 4.7.2 или выше).
2. Скачайте или клонируйте репозиторий:
3. Откройте файл решения TicTacToe.sln в Visual Studio (2019 или новее).
4. Нажмите клавишу F5 или выберите пункт меню Отладка → Начать отладку, чтобы запустить игру.
